# Chapter Solutions
This repository contains sample solutions, notebooks, scripts, DAX measures, semantic model artifacts, and other supporting materials referenced throughout the book Analytics Engineering with Microsoft Fabric and Power BI.

## About This Repository
The files in this repository are organized by chapter and provide working examples that demonstrate concepts covered in the book. These resources are intended to help readers follow along, experiment with the examples, and deepen their understanding of analytics engineering practices in Microsoft Fabric and Power BI.

## Companion Repositories
This book uses two GitHub repositories:

### SampleData
Contains the datasets used throughout the book, including customer, sales, purchasing, warehouse, and order data.

### ChapterSolutions
Contains the code, notebooks, DAX measures, sample semantic models, scripts, and other artifacts referenced in specific chapters.

### Prerequisites
Examples assume that you have already downloaded the sample datasets from the SampleData repository and loaded them into Microsoft Fabric.

### Notes
All data used in the examples is synthetic and provided for educational purposes.
Solutions are provided as learning aids and may not represent the only valid implementation.
Some artifacts are simplified to focus on specific concepts discussed in the book.

## Feedback and Updates
As Microsoft Fabric continues to evolve, examples and solutions may be updated over time. Be sure to pull the latest version of the repository to access corrections, improvements, and additional chapter content.
